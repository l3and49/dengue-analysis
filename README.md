# Dengue Analysis

Projeto Integrador - Análise de dados de dengue utilizando dados abertos do Ministério da Saúde.

## Objetivo

Desenvolver uma aplicação para coleta, análise e visualização de dados de dengue, utilizando técnicas de análise de dados e aprendizagem de máquina.

## Fonte dos dados

Ministério da Saúde - Dados Abertos.

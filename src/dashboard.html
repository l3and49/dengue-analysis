Fluxo de Engenharia de Dados (Pipeline)

Como transformamos dados brutos de saúde em inteligência acionável:

1. Extração Conexão direta com a API oficial do Ministério da Saúde.
2. Tratamento Limpeza de nulos, padronização e estruturação em CSV.
3. Visualização Geração automatizada de gráficos de evolução e perfil.
4. Machine Learning Modelo Random Forest de alta precisão preditiva.

Principais Insights Analíticos (Feature Importance)

Com base na análise inteligente dos dados, o modelo apontou quais características possuem maior peso preditivo nos registros analisados:

  • Escolaridade e Perfil Demográfico: Fatores socioeconômicos e de escolaridade demonstraram forte relevância estrutural nos padrões de notificação.
  • Variáveis Clínicas e Evolução: O cruzamento de dados de evolução do quadro clínico garantiu a robustez necessária para atingir a marca de 98.48% de precisão analítica.
